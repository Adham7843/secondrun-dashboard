Letters to the editor

Is it only YC startups? +

We started with YC because its batches are the best-documented graveyard in tech. We are expanding to every accelerator and indie shutdown with a paper trail.

What is a rebuild plan? +

A concrete second attempt: the wedge the original missed, a technical spec for 2026 tooling, and the failure modes to avoid — so you don’t die the same way.

Can I request a startup? +

Yes. Pro members file up to 5 fresh requests a month, and our researchers pull the filings, interviews, and post-mortems into a new dossier.

Do I install anything? +

No — it’s a library. Open a dossier in your browser, read the autopsy, and copy the rebuild prompt into whatever agent or editor you already use.
